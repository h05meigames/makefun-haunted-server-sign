Entry for the make.fun bounty [Funniest Sign on a Haunted Server Room Door](https://make.fun/bounty/u-eager-stork-81-9647-funniest-sign-on-a-haunted-ab1d019a): one funny line for the door of a haunted server room, at most 120 characters. An AI judge compares the lines two at a time and keeps the funnier one; a single winner takes the $2 USDC reward.

## The sign

> DO NOT UNPLUG THE GHOST. IT IS THE ONLY ONE WHO KNOWS WHERE THE BACKUPS ARE.

**76 characters** — within the 120-character limit.

## Run it

```sh
node main.ts
```

Writes the single line to `/output/entry.txt` and prints it with its character count.
